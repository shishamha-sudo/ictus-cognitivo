# ICTUS Cognitivo

Aplicación web de entrenamiento cognitivo con ejercicios de figuras, colores, palabras y figuras complejas.

## Versión
v2.4 · 17/10/2026

## Uso
La aplicación está preparada para GitHub Pages y funciona en PC, tablet y móvil.

Los resultados de esta primera versión web se guardan localmente en el navegador de cada dispositivo y no se publican en GitHub.

> Herramienta de entrenamiento. No sustituye una valoración médica o neuropsicológica.
